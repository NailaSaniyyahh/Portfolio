# Portfolio Website - Naila Saniyyah

A modern, responsive personal portfolio website built for a Fresh Graduate in Informatics Engineering.

## ✨ Features
- **Design & Theme**: Soothing nature-inspired sage & mint green palette with gentle off-white surfaces (no glare).
- **Background**: Ambient canvas particle motes with smooth physics and zero distraction.
- **Tech Stack**: Vanilla HTML5, CSS3, Bootstrap 5.3.8, and Vanilla JavaScript (zero npm/build dependencies).
- **Showcase**: Academic and personal projects, credential badges, and technical skills matrix.

## 🚀 Deployment
This project is ready to deploy directly with **GitHub Pages**:
1. Push this repository to GitHub.
2. In your repository on GitHub, go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your site will be live at `https://nailaanai.github.io/<repo-name>/`!
